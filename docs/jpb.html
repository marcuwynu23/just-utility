jpb — Java Project Builder

Synopsis

jpb [--help | -h] [option] [args...]

Description

A complete Java project build tool for initializing, managing packages, compiling, packaging JARs, and generating docs.

Options

OptionDescription
--initInitialize a new Java project structure
--mdCreate package directory structure
--cfCreate a new Java source file
--aimAdd import statement to a source file
--adepsAdd dependency JARs to classpath
--compileCompile the project source files
--compile-depsCompile with dependencies
--docsGenerate Javadoc documentation
--runRun the compiled Java project
--testRun tests in the project

Dependencies

javac, jar (JDK), cf utility

Examples

jpb --init
jpb --compile
jpb --cf com.example Main.java
