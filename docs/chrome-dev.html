NAME

chrome-dev - Open Chrome with DevTools

SYNOPSIS

chrome-dev [--help | -h] [url]

DESCRIPTION

Opens Google Chrome with Developer Tools automatically opened for the given URL.

OPTIONS

OptionDescription
--help, -hDisplay help information

ARGUMENTS

ArgumentDescription
urlThe URL to open in Chrome (optional)

DEPENDENCIES

  • Google Chrome

EXAMPLES

chrome-dev http://localhost:8000
chrome-dev https://example.com
