NAME

cci - C interpreter (compile + run)

SYNOPSIS

cci [--help | -h] [sourcefile]

DESCRIPTION

Compiles and runs a C source file in one step. The file is compiled with clang, executed, then the binary is cleaned up. Shows compile and execution times.

OPTIONS

OptionDescription
--help, -hDisplay help information

ARGUMENTS

ArgumentDescription
sourcefileThe C source file to compile and run (without or with .c extension)

DEPENDENCIES

  • clang (LLVM)

EXAMPLES

cci hello
cci --help
