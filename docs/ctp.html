NAME

ctp - Create project templates

SYNOPSIS

ctp [--help | -h] [language] [project-name]

DESCRIPTION

Creates a project directory structure for the specified language or project type.

LANGUAGES

LanguageDescription
javaJava project structure
pythonPython project structure
js-web-appJavaScript web application structure
php-web-appPHP web application structure
c/cppC/C++ project structure
webGeneral web project structure

OPTIONS

OptionDescription
--help, -hDisplay help information

ARGUMENTS

ArgumentDescription
languageThe project language or type
project-nameThe name of the project (creates a subdirectory)

DEPENDENCIES

  • cf utility
  • Windows md command

EXAMPLES

ctp java myapp
ctp python myapp
